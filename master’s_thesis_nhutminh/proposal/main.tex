\begin{abstract}
Many parking facilities record vehicles with low-cost overview cameras, so a license plate in the
footage may cover only about $46\times19$ pixels, and a single frame often does not hold enough
detail for a reliable reading. This proposal describes PlateReader LR, a web application for parking
operators that restores and reads such plates from a short track of up to five frames, and shows which
readings can be accepted automatically and which need a check by staff. The system serves MF-SR-OCR, a multi-frame
recognition model that reaches $79.95\%\pm0.15$ exact-match accuracy over three seeds on 999
validation tracks of the ICPR 2026 LRLPR benchmark, against $75.78\%$ for a retrained CRNN+STN
baseline. Around the model, the project builds a FastAPI service, a PostgreSQL store for results and
reviews, a React review interface, and a Docker Compose deployment for CPU-only machines. The
backend, its database and its tests were completed in Weeks 1--2; the API reproduces the offline model
on all 999 validation tracks. The remaining ten weeks cover statistical validation on a sealed test
set, confidence-based routing to reviewers, the user interface, CI/CD, and a five-user study.
\keywords{license plate recognition \and low-resolution images \and multi-frame super-resolution
\and parking management \and selective prediction \and web application}
\end{abstract}
